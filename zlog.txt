1.编译过程
    预处理源代码使用-E选项，生成.i文件
    g++ -E helloworld.cpp -o hello.i
    编译.i文件使用-S选项，生成.s文件,汇编语言
    g++ -S hello.i -o hello.s
    汇编.s文件使用-c选项，生成.o文件
    g++ -c hello.s -o hello.o
    链接.o文件无需使用选项，生成.exe文件
    g++ hello.o -o hello
  重要编译参数
    -g 产生带调试信息的可执行文件 
    g++ -g helloworld.cpp
    -O[n] n为0、1(默认)、2、3优化源代码，如省略未使用过的变量、将常量表达式用结果值代替等
    g++ -O2 helloworld.cpp
    -I 指定头文件搜索目录
    g++ -I/myinclude helloworld.cpp
  编译环境MSYS32+MINGW64：
    MINGW64(GCC)：
      64 位 x86 编译环境。
      使用传统 MSVCRT 运行库。
      主要编译器：GCC（安装后提供 g++）。
      适合需要兼容较老 Windows 的程序。
    UCRT64(GCC):
      64 位 x86 编译环境。
      使用 UCRT 运行库。
      主要编译器：GCC（安装后提供 g++）。
      面向较新的 Windows 系统
    CLANG64(Clang):
      64 位 x86 编译环境。
      使用 UCRT。
      默认编译器：Clang / Clang++。
      适合使用 LLVM 工具链的项目
    CLANGARM64(Clang):
      ARM64 架构编译环境。
      面向 Windows ARM64 设备。
      默认编译器：Clang / Clang++。
      不适合直接编译给普通 x86-64 Windows 7 电脑运行的程序
    MSYS(Unix 工具环境):
      主要用于运行 Bash、Shell、Pacman 等工具。
      不是面向原生 Windows 程序的主要 GCC 环境。
      可以安装 MSYS 自身的 GCC，但生成的程序通常依赖 MSYS 运行环境。
      
    严格来说有三套可以使用 GCC/G++ 的环境，另外两套主要使用 Clang/Clang++
    终端	  默认编译器	 是否有 g++	   目标架构
    MSYS	    GCC	        有（安装后）	x86-64
    MINGW64	    GCC	        有（安装后）	x86-64
    UCRT64	    GCC	        有（安装后）	x86-64
    CLANG64	    Clang	  默认是 clang++    x86-64
    CLANGARM64	Clang	  默认是 clang++	ARM64
2.for和while的优缺点
    for适合已知循环次数、局部变量控制、更紧凑的语法；灵活性较低
    while适合未知循环次数、更灵活的条件控制、更简洁的无限循环；循环变量需手动控制

4.本地文件同步到github上
    初始化本地仓库
    git init
    添加所有文件到暂存区
    git add .
    提交文件
    git commit -m "initial commit"
    添加远程仓库
    git remote add origin 仓库地址
    验证远程仓库
    git remote -v
    推送代码
    git push -u origin master
5.WSL
  wsl --list --online 以查看可用发行版列表并运行
  wsl --install -d <DistroName> 以安装发行版
  wsl --install --web-download -d <DistroName> 下载发行版，然后再进行安装，而不是使用 Microsoft Store
  wsl --install -d [发行版] 默认安装 Ubuntu，可以通过使用-d标志来更改这一点：
  wsl --list --verbose 列出已安装的 Linux 发行版
  wsl --location 指定要将 WSL 分发版安装到哪个文件夹
  wsl --update 将 WSL 版本更新为最新版本
  wsl --unregister <DistributionName> 注销和卸载 WSL 分发版
  查找它的物理位置,Linux 下的软件、文档等放在一个虚拟磁盘里面,BasePath 就是它的物理位置:
    Get-ChildItem "HKCU:\Software\Microsoft\Windows\CurrentVersion\Lxss" -Recurse
    可使用导出/导入的方法进行迁移 
    1.关闭所有 WSL 实例：wsl --shutdown
    2.将指定发行版导出为 tar 包：wsl --export Ubuntu D:\path\backup\ubuntu-backup.tar
    3.注销原有的发行版：wsl --unregister Ubuntu 
    4.在新位置重新导入：wsl --import Ubuntu D:\new\wsl\location D:\path\backup\ubuntu-backup.tar --version 2
